# The Veil Between Twilight and Dawn
A turn-based mixed reality board game of galactic conquest, designed by Arlen Roy Kundert. Three asymmetric factions manage an economy, expand through star systems and fight over a three-dimensional tactical board. Players handle miniatures and consult three movable tablets at tabletop scale.

**Development target:** Quest 3, bare hands first, Unity 6.6 and URP. **Current repository scope:** design, production workflow and evidence from the ship prototype. The playable Unity project still needs to be inventoried and imported.
